# Mi PWA - Service Workers

Práctica de PWA: service worker (`sw.js`), `manifest.json` e íconos.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a un repositorio (`index.html` en la raíz).
2. En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
3. Espera ~1 min. La URL será `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Instalar en el celular
- Abre la URL (HTTPS) en Chrome (Android) o Safari (iPhone).
- Android: menú ⋮ → **Instalar aplicación** / **Agregar a pantalla de inicio**.
- iPhone: botón Compartir → **Agregar a pantalla de inicio**.

## Probar en local
`python3 -m http.server 8000` y abre `http://localhost:8000`.
